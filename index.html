About Parallax

PLX is the native cryptocurrency of the Parallax blockchain. The network uses Scrypt Proof-of-Work and public mining, while Parallax Core combines a full blockchain node, wallet and integrated mining interface in one Windows application.

Independent Blockchain

Parallax operates from its own Genesis Block at height 0 and maintains its own blockchain, peer-to-peer network, transaction history and native PLX currency.

Scrypt Proof-of-Work

Blocks are secured through Scrypt Proof-of-Work. The current block subsidy is 50 PLX, distributed through network mining.

Full Node, Wallet & Miner

Parallax Core provides blockchain synchronization, transaction management and integrated solo mining from a single desktop application.
