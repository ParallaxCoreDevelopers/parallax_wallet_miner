What Is Parallax (PLX)?

Parallax (PLX) is a native cryptocurrency operating on its own independent blockchain. It is not an ERC-20 token, BEP-20 token or smart-contract token hosted on another blockchain. PLX is created and transferred directly on the Parallax network.

The Parallax blockchain uses Scrypt Proof-of-Work consensus. Miners contribute hashing power to create blocks, confirm transactions and secure the blockchain. The current block subsidy is 50 PLX per block.

Native PLX Cryptocurrency

PLX is the native currency of the Parallax blockchain and is recorded directly on its own blockchain rather than through a token contract.

Layer 1 Blockchain

Parallax operates its own base-layer blockchain, peer-to-peer network, transaction history, consensus rules and Genesis Block 0.

Scrypt Proof-of-Work

The network uses Scrypt mining and public Proof-of-Work participation to produce blocks and maintain blockchain consensus.

Open Source

Parallax mainnet source code, wallet software, documentation and releases are publicly available through the official GitHub repository.

Parallax Core: Full Node, Wallet, Miner, Security & Network Tools

Parallax Core is not simply a Layer 1 wallet. Parallax is the Layer 1 blockchain. Parallax Core is the official Windows full-node desktop client used to participate directly in that network.

The application combines blockchain validation, a native PLX wallet, integrated Scrypt mining, wallet encryption, backup tools, message signing and verification, peer information, network traffic monitoring, node information and an RPC console. Users can choose whether or not to mine using the built-in Start/Stop Mining controls.

Full Blockchain Node

Downloads, validates and maintains the Parallax blockchain locally so users can independently verify network activity.

Native PLX Wallet

Provides sending, receiving, address management, transaction history and locally controlled wallet functionality for native PLX.

Integrated Scrypt Miner

Includes graphical Start Mining and Stop Mining controls directly inside Parallax Core. Mining is optional and controlled by the user.

Peer & Traffic Information

Displays connected peers, network traffic and information about the user's Parallax node and its blockchain connections.

RPC Console

Provides advanced blockchain and node access for experienced users, developers and network administration.

One Application

Full Node. Wallet. Miner. Security. Network Tools. One application.

Scrypt Cryptocurrency Mining

Parallax is a mineable Proof-of-Work cryptocurrency. The Parallax network uses the Scrypt hashing algorithm, allowing miners to contribute computing power to produce new blocks and secure the blockchain.

Parallax Core includes an integrated solo-mining interface so users do not need to use command-line controls simply to start or stop mining. Compatible external Scrypt mining software may also be used where supported.

Current Mining Reward

The current blockchain subsidy is 50 PLX per block. Newly mined PLX is recorded directly on the Parallax blockchain.

Parallax Core Wallet Security

Parallax Core includes security features for users who hold and manage PLX locally. These features are integrated directly into the official full-node application rather than relying on a hosted custodial wallet service.

Wallet Encryption

Users can encrypt the local wallet and protect access using a wallet passphrase.

Wallet Backup

Built-in wallet backup functionality allows users to create copies of important wallet data for recovery and safekeeping.

Message Signing

Sign and verify messages using cryptocurrency addresses without moving PLX.

Local Key Control

Parallax Core is designed around locally controlled wallet data rather than requiring a hosted exchange account to hold native PLX.

Users remain responsible for protecting wallet backups, passphrases, private keys, operating systems and devices. Private wallet credentials should never be shared.
