Parallax (PLX) Whitepaper

Independent Layer 1 Scrypt Proof-of-Work Blockchain

Abstract. Parallax (PLX) is an independent, open-source Layer 1 blockchain with its own genesis block, peer-to-peer network, consensus rules, transaction history and native cryptocurrency. The network currently uses Scrypt Proof-of-Work. Parallax Core is the official Windows full-node application combining blockchain validation, a native PLX wallet, integrated mining controls and network tools.

This document describes the project's currently documented network design and economic model. Planned features and economic targets that are not enforced by mainnet consensus are identified as plans, not live protocol rules.

1. Project Overview

Parallax is a base-layer blockchain, not a token deployed through a smart contract on another network. PLX is the native asset recorded directly in the Parallax blockchain. The network maintains its own block history, transaction validation, peer-to-peer communication and consensus process.

The project aims to provide a publicly verifiable Proof-of-Work network and desktop software that lets users operate a node, hold and transact in native PLX, and optionally contribute mining work through one application.

3. Consensus and Mining

Parallax currently uses Scrypt Proof-of-Work. Miners perform computational work to propose valid blocks. Nodes independently validate blocks and transactions against the network's consensus rules before accepting them into their local chain.

The documented mainnet target block interval is four minutes. Difficulty retargeting is configured around a 2,016-block adjustment interval and a 5.6-day target timespan. These parameters govern the intended rate of block production and periodic adjustment of mining difficulty.

The current block subsidy is 50 PLX per accepted block. Mining distributes newly created PLX under the active consensus rules and contributes Proof-of-Work to the chain. Coinbase rewards require one additional block before becoming mature, as documented in the project README.

Mining hardware and future work: Scrypt is the current mainnet algorithm. Specialised Scrypt hardware can have a substantial hashrate advantage over ordinary CPUs and GPUs. The project has publicly stated that it is evaluating possible future Proof-of-Work changes intended to improve general-purpose CPU/GPU participation. No replacement algorithm or activation height is announced here; any consensus change must be tested, documented and announced before activation.

Mining participation is permissionless at the protocol level, subject to the network's software, hardware and consensus requirements. The project does not promise fixed mining income or a guaranteed probability of finding blocks.

4. Parallax Core: Full Node, Wallet and Miner

Parallax Core is the official Windows desktop software for participating directly in the Parallax network. It is more than a standalone wallet interface: when synchronised, it operates as a full node and validates blockchain data locally.

Full-node functions

  • Synchronises and maintains local blockchain data.
  • Validates blocks and transactions according to the software's consensus rules.
  • Connects to peers on the Parallax peer-to-peer network.
  • Displays peer connections, network traffic and node information.
  • Provides an integrated console for advanced functions.

Native wallet functions

  • Creates and manages PLX receiving addresses.
  • Sends and receives native PLX.
  • Displays balances and transaction history.
  • Supports wallet backup, message signing and message verification.
  • Keeps wallet private-key management under the user's local control.

Integrated mining

The desktop interface includes Start Mining and Stop Mining controls for the integrated Scrypt mining function. Users can choose whether to mine while operating the wallet and node.

5. Wallet Security and User Responsibilities

Parallax Core includes wallet encryption, passphrase management, wallet backup, message signing and verification. Wallet encryption helps protect locally stored wallet information if the wallet file or computer is accessed without authorisation.

Encryption does not remove the user's responsibility to secure their computer, passphrase and backups. A lost passphrase may permanently prevent access to an encrypted wallet. Backups should be stored securely and separately from the computer running the wallet.

  • Download software only from official Parallax project sources.
  • Verify the published SHA256 checksum before running the executable.
  • Use a strong, unique wallet passphrase.
  • Keep encrypted wallet backups in secure separate storage.
  • Never disclose private keys or wallet passphrases.
  • Keep RPC access restricted to localhost or trusted systems; do not expose RPC credentials publicly.
  • Check recipient addresses carefully before sending PLX.

No Proof-of-Work blockchain or desktop application can guarantee protection against every possible software, infrastructure, endpoint or majority-hashpower attack. Users should review current security notices and use the current supported release.

6. Network Security and Validation

Parallax Core's full-node design allows a synchronised client to process and validate blockchain data locally rather than relying solely on a third-party wallet service. Peer-to-peer networking distributes blocks and transactions between participating nodes.

The project's published security update describes work on full-period difficulty-retarget protection, checkpoint protection for established chain history, accumulated-chainwork validation and fork detection. These mechanisms are intended to make specific forms of timestamp and difficulty manipulation more difficult and to protect established chain history. They do not make the network immune to every possible attack.

Mainnet uses P2P port 19339. RPC uses port 19340 and should normally remain restricted to localhost or trusted systems.

7. PLX Supply and Tokenomics

PLX is issued through Proof-of-Work mining. The live mined supply is determined by the blockchain and can be independently inspected through the official block explorer. The explorer, rather than a manually maintained website figure, is the authoritative public reference for current on-chain supply.

The project's published long-term economic model uses a planning target of one billion PLX, with the following intended allocation:

Important distinction: The one-billion-PLX figure and allocation table describe the project's intended long-term economic model. They are not a statement that these amounts have been minted, pre-allocated or implemented as an enforced on-chain hard cap. The project's tokenomics documentation says the detailed long-term emission and allocation implementation remains under review against active mainnet consensus rules.

PLX is a native blockchain asset. It is not currently an ERC-20 or BEP-20 token and does not have a smart-contract token address on those networks.

8. Open-Source Development

Parallax Core is published as open-source software under the MIT License. The public repository provides source code, release information, project documentation and security guidance. The current published Windows mainnet release is Parallax Core Full-Node Wallet & Miner v0.1.4.

Users should compare downloaded software against the published release information and checksum.

9. Roadmap and Future Development

Publicly documented areas of ongoing work include improving mining accessibility, maintaining network security, strengthening wallet and node usability, and evaluating broader PLX wallet and trading compatibility.

The project has discussed a possible future representation of PLX on an established network to support wider wallet compatibility and potential trading integrations. No token contract address, bridge mechanism or trading pair is announced here. Such details should only be relied upon when published with implementation and verification information by the project.

Any future consensus change must be tested and publicly documented before activation. This whitepaper describes the currently documented network and distinguishes it from proposals that remain under evaluation.
