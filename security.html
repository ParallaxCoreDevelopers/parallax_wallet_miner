Parallax (PLX) Blockchain & Wallet Security

How Parallax protects consensus integrity, blockchain history, node communications and locally managed wallets.

Parallax is an independent Layer 1 Proof-of-Work blockchain with its own genesis block and native PLX asset. Security relies on multiple safeguards working together: network consensus checks, mining validation, blockchain history protections and wallet features.

This page provides a public-facing overview of those protections without disclosing sensitive implementation details.

Eight Layers of Parallax Security

These descriptions explain the purpose of each protection. They do not imply that all eight were introduced in the same security update.

01 / NETWORK

Mining difficulty protection

Helps prevent attempts to manipulate the network's mining difficulty and destabilise block production.

02 / BLOCKCHAIN

Blockchain history protection

Helps protect established blockchain records against certain attempts to replace or rewrite accepted history.

03 / CONSENSUS

Consensus integrity

Ensures blocks must satisfy Parallax's validation rules before nodes accept them.

04 / MINING

Proof-of-Work verification

Ensures miners cannot simply announce arbitrary blocks and have them accepted without satisfying the network's mining requirements.

05 / CONSENSUS

Mathematical safety protections

Prevents certain invalid or extreme calculation results from interfering with consensus decisions.

06 / CHAIN VALIDATION

Chain-selection and fork safeguards

Helps nodes distinguish valid blockchain history from competing or incompatible chain data.

07 / NODES

Network and node security

Provides peer validation and separates sensitive administrative access from ordinary public network connections.

08 / WALLET

Wallet security

Includes encryption, passphrase protection, local private-key control, wallet backups and cryptographic signature verification.

Important distinction: The difficulty, history and calculation safeguards include specific security hardening work. Other items are existing protections or wallet features, rather than entirely new patches.

Security Hardening Following a Previous Incident

Following a previous network security incident, Parallax implemented substantial security hardening, including additional safeguards for mining difficulty, blockchain history and mathematical consensus calculations.

The project has not observed another attack since these changes were introduced. This is an observation about the period since the update, not a guarantee that future attacks are impossible.

As with other Proof-of-Work networks, Parallax cannot guarantee immunity against every majority-hashpower attack or other security threat. Security is an ongoing engineering and monitoring responsibility.

Wallet Security and Safe Practices

Parallax Core is designed to let users manage their native PLX locally rather than requiring a hosted custodial wallet. Wallet security also depends on how each user protects their device and recovery information.

  • Encrypt your wallet with a strong, unique passphrase where supported.
  • Back up wallet data securely and verify that backups can be recovered.
  • Protect private keys and passphrases. Never share them with support accounts, websites or strangers.
  • Verify software downloads against the official release and published checksum before running them.
  • Keep your operating system secure and avoid installing wallet software from unofficial links.

Verify Official Parallax Software

Download Parallax Core only from the project's official release source. Compare the downloaded file's SHA-256 hash with the checksum published for that exact release. A checksum helps confirm file integrity when the expected value comes from a trusted source; it is not a substitute for assessing the publisher or software security.
