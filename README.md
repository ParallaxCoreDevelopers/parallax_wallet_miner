# Parallax (PLX)

**Parallax (PLX)** is an independent, open-source **Scrypt Proof-of-Work cryptocurrency and Layer-1 blockchain**.

Parallax operates from its own **Genesis Block at height 0**, with its own peer-to-peer network, blockchain history and native cryptocurrency, **PLX**.

The official desktop application, **Parallax Core**, is much more than a cryptocurrency wallet.

**Full Node. Wallet. Miner. Security. Network Tools. One application.**

## What Is Parallax Core?

Parallax Core is the official Windows software for participating directly in the Parallax network.

It combines multiple functions that would often require separate applications.

### Full Blockchain Node

Parallax Core operates as a full network node.

The application can:

- Synchronise the Parallax blockchain
- Validate blockchain data
- Maintain the local blockchain state
- Connect to Parallax peers
- Relay network information
- Participate directly in the peer-to-peer network
- Display peer connections
- Display network traffic
- Provide node information and diagnostics
- Provide an integrated console for advanced functionality

A fully synchronised Parallax Core client is therefore not simply a wallet interface — it is an active participant in the Parallax blockchain network.

## Native PLX Wallet

Parallax Core includes a native wallet for the PLX cryptocurrency.

Wallet functionality includes:

- Creating wallet addresses
- Receiving PLX
- Sending PLX
- Viewing balances
- Viewing transaction history
- Managing receiving addresses
- Managing sending addresses
- Signing messages
- Verifying signed messages
- Wallet backup functionality

Private keys are managed by the user's local Parallax Core wallet.

## Integrated Wallet Security

Security functions are built directly into Parallax Core.

Users can encrypt their wallet using a passphrase from within the application.

Available wallet-security functions include:

- Encrypt Wallet
- Change Passphrase
- Backup Wallet
- Sign Message
- Verify Message
- Local private-key ownership
- Full-node blockchain validation
- Peer and network inspection tools

Wallet encryption helps protect locally stored private-key material if the wallet file or computer is accessed without authorization.

Users remain responsible for protecting their passphrase, wallet backups, operating system and computer.

**A lost wallet passphrase cannot simply be recovered by the network.**

For this reason, encrypted wallet backups should be stored securely and separately from the computer running Parallax Core.

## Integrated Scrypt Mining

Parallax Core includes native Scrypt Proof-of-Work mining directly inside the desktop application.

Users do not need a separate terminal-based mining program to participate in native Parallax solo mining.

The graphical interface includes a built-in:

**Start Mining / Stop Mining**

control.

Current block subsidy:

**50 PLX per block**

Mining helps:

- Secure the Parallax blockchain
- Extend the blockchain
- Validate network history
- Provide Proof-of-Work
- Distribute newly mined PLX

Newly mined coinbase rewards currently require one additional block before becoming mature.

## Security

Parallax Core includes integrated wallet and node security functionality, but users must also maintain good computer security.

Recommended practices:

1. Download Parallax Core only from official project sources.
2. Verify the SHA256 checksum before running the executable.
3. Encrypt the wallet with a strong passphrase.
4. Create secure wallet backups.
5. Store backups separately from the main computer.
6. Never share private keys.
7. Never share wallet passphrases.
8. Never expose RPC credentials publicly.
9. Keep the operating system protected and updated.
10. Verify transaction and address information before sending PLX.

Security policy:

https://github.com/ParallaxCoreDevelopers/parallax_wallet_miner/blob/main/SECURITY.md

Private keys, wallet databases, RPC credentials, blockchain data, private backups and local configuration files are not included in the public source repository.
